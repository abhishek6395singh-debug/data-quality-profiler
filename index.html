Data Quality Profiler

Check a client file before it is loaded. You get a quality score, the rows that fail and why, and a summary you can paste into a ticket or an email. The file is read in your browser and is not uploaded anywhere.

Load a file

Drop a CSV, TSV, pipe-delimited or Excel file here. Only the first sheet of a workbook is read, as displayed in Excel.

Checks run on text exactly as it appears in the file. Row numbers count the header as row 1, so they match what you see in Excel. Text files are read as UTF-8 and up to 250,000 rows are checked. The currency check uses a list of 40 common ISO 4217 codes, so an unusual but valid code shows up as unknown. The sample is synthetic and contains no real investors or securities.
